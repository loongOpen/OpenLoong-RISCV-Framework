# OpenLoong RISC-V Framework

面向 RISC-V 架构与 OpenHarmony 操作系统的人形机器人底层软件适配实践

## 项目简介

OpenLoong RISC-V Framework 是面向 RISC-V 架构与 OpenHarmony 操作系统的适配项目，围绕 RISC-V 硬件平台与 OpenHarmony 操作系统的适配需求，开展人形机器人底层运行环境适配、项目系统接口兼容及相关功能验证工作，探索开源软件框架在不同硬件架构和操作系统环境下的部署与应用。

本项目旨在推动进迭主控相关软件框架在 RISC-V 平台上的兼容与运行，为人形机器人及相关嵌入式应用提供开放的软件适配参考，降低开发者在新硬件平台上的环境搭建、驱动部署、软件移植与应用开发成本。

仓库主要提供硬件环境准备、系统烧录、开发调试、驱动部署、交叉编译及应用运行等相关技术文档、配置模板与辅助脚本，帮助开发者完成从硬件平台初始化到软件应用部署的基础流程。

## 项目目标

- **硬件平台适配：** 探索人形机器人相关软件框架在 RISC-V 硬件平台上的运行与适配。
- **操作系统兼容：** 开展 OpenHarmony 系统环境下的接口兼容、运行环境配置及相关功能验证。
- **驱动部署与验证：** 提供 CAN、USB 串口等相关驱动的编译、部署、加载与验证参考。
- **开发环境搭建：** 梳理系统烧录、HDC 调试、SSH 连接、文件传输及交叉编译等基础开发流程。
- **开放技术参考：** 通过文档、配置模板与辅助脚本，沉淀可复用的适配经验，支持开发者开展机器人及嵌入式应用开发。

## 适用范围

本项目主要面向以下开发场景：

- 基于 RISC-V 架构硬件平台开展人形机器人软件开发。
- 在 OpenHarmony 操作系统环境下部署和运行相关软件框架。
- 进行机器人底层运行环境、系统接口及驱动适配。
- 开展 CAN 通信、USB 串口、系统调试及应用部署等相关工作。
- 探索机器人软件框架在不同硬件架构与操作系统环境下的兼容性。

> 本仓库提供的文档、脚本及配置模板主要用于适配实践参考。具体操作步骤、驱动版本及功能支持情况以对应硬件平台、系统版本和实际验证结果为准。

## 开发环境

开展适配工作前，请根据实际硬件平台及系统版本准备以下环境。

| 环境 | 说明 |
|---|---|
| RISC-V 硬件平台 | 项目适配所使用的目标板卡及相关硬件设备 |
| OpenHarmony 操作系统 | 适配所使用的系统镜像及对应版本 |
| 开发主机 | 用于系统烧录、开发工具运行、交叉编译及文件传输 |
| HDC 工具 | 用于设备连接、命令执行、文件传输及调试 |
| 交叉编译工具链 | 根据目标硬件架构及系统环境选择对应工具链 |
| 驱动及相关依赖 | 根据目标平台的硬件接口及系统版本准备 |

具体硬件型号、系统版本、工具链版本、驱动来源及配置要求，请参考：

- [硬件与环境准备](docs/01_硬件与环境准备.md)
- [外部资源与版本说明](docs/10_外部资源与版本说明.md)

## 快速开始

建议首次使用的开发者按照以下顺序完成环境准备及基础适配。

### 1. 硬件与环境准备

确认目标硬件平台、开发主机、连接方式及相关设备，完成必要的硬件连接与环境配置。

参考文档：[01_硬件与环境准备](docs/01_硬件与环境准备.md)

### 2. 系统烧录

获取对应硬件平台的系统镜像，按照文档完成系统烧录及初始启动。

参考文档：[02_系统烧录](docs/02_系统烧录.md)

### 3. 设备连接与调试

通过 HDC 建立设备连接，完成设备识别、命令执行及基础调试。

参考文档：[03_HDC连接与调试](docs/03_HDC连接与调试.md)

### 4. 驱动部署与验证

根据实际硬件接口需求，完成相关驱动的编译、部署及功能验证。

- [CAN 驱动部署与验证](docs/04_CAN驱动部署与验证.md)
- [USB 串口驱动编译与部署](docs/05_USB串口驱动编译与部署.md)
- [驱动开机自启动](docs/06_驱动开机自启动.md)

### 5. 应用编译与部署

根据目标平台配置交叉编译环境，完成应用程序编译、文件传输及板端运行验证。

参考文档：[08_交叉编译与应用部署](docs/08_交叉编译与应用部署.md)

## 版本与适配说明

本项目适配工作涉及硬件平台、操作系统、工具链及驱动等多个组件，不同版本之间可能存在兼容性差异。

为确保适配过程可复现，建议开发者在使用前确认：

- 目标硬件平台及其版本。
- OpenHarmony 系统版本及镜像来源。
- 交叉编译工具链版本。
- 相关驱动及依赖组件版本。
- 当前文档对应的适配环境与验证情况。

相关信息将持续更新至 [外部资源与版本说明](docs/10_外部资源与版本说明.md)。
