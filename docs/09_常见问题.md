# 09 常见问题

[返回首页](../README.md)

| 现象 | 检查方向 |
| --- | --- |
| HDC 无法连接 | IP、网络、板端 TCP 调试开关、55555 端口、HDC 版本；多设备时明确指定 `-t` |
| 串口打不开 | 实际设备节点、用户权限、串口占用、波特率和接线 |
| `insmod` 提示格式无效 | ELF 架构、vermagic、精确内核配置、编译器及 ABI；查看 `dmesg` |
| 未解析符号 | 核对模块加载顺序、导出符号和匹配构建输出；编译告警不能当作兼容性通过 |
| 加载 CAN 后没有接口 | 检查 flexcan 模块、设备树、驱动探测日志和镜像配套关系 |
| CAN 接口存在但没有报文 | 核对 CAN_H/L、共地、终端电阻、通道、模式和两端速率；观察错误计数 |
| CAN FD 发送 `EINVAL` | 检查帧长度、flags、接口 FD 配置和应用帧初始化；历史 SDK 曾发现 flags 未初始化 |
| CAN 发送 `ENOBUFS` | 检查发送队列、总线错误、ACK、对端模式及 TX 完成情况；增大队列不等于修复根因 |
| 没有 `/dev/ttyUSB0` | 检查 USB 芯片及绑定驱动、线缆、dmesg；实际节点可能是 ttyUSB1 等 |
| 自启动未执行 | 检查 vendor import、JSON、服务路径、权限、SELinux 和 load-drivers.log |
| USB 未接时自启动无串口节点 | 正常可能；先确认模块已加载，再插入设备检查绑定 |
| 重刷后自启动消失 | vendor 配置或 data 文件被刷写覆盖，需要按新镜像重新部署验证 |
| 文件存在却无法执行 | 检查 ELF 架构、解释器路径、权限、挂载选项和运行库 |
| glibc 版本/符号报错 | 加载器、libc、应用及间接依赖是否来自兼容环境，有无混用 musl/x86_64 库 |
| SSH 主机密钥检查失败 | 先从可信通道核对指纹及是否重刷/换板，不直接绕过主机身份检查 |
| SSH 公钥认证失败 | 检查有效配置、authorized_keys 内容、文件路径、属主、权限和日志 |
