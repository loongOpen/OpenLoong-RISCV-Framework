# 10 外部资源与版本说明

| 项目开源手册 | `进迭主控+鸿蒙系统开源手册.pdf` | [仓库内 PDF](../resource/进迭主控%2B鸿蒙系统开源手册.pdf) |
| Linux 烧录工具 | `titantools_for_linux-2.3.2-Rc.AppImage` | [仓库内 AppImage](../resource/titantools_for_linux-2.3.2-Rc.AppImage) |
| OpenHarmony 固件 | `spacemit-k3-oh61-com260-normal-V1.0-20260917.zip` | [仓库内固件包](../resource/spacemit-k3-oh61-com260-normal-V1.0-20260917.zip) |
| CAN 驱动/工具包 | `can_tools_k3_oh61_6.18.3_20260929.tar.gz` | [仓库内 CAN 包](../resource/can_tools_k3_oh61_6.18.3_20260929.tar.gz)；解压得到 `can_tools/`，含四个 CAN 模块、`ip`、`candump`、`cansend` 和 README |

| 厂商公开 Linux 源码 | `k3-br-v1.0.y`，历史记录 Makefile 为 6.18.3 | [外部源码分支](https://github.com/spacemit-com/linux-6.18/tree/k3-br-v1.0.y) |
